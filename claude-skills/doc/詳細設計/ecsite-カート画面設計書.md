# ecsite カート画面設計書

画面名: カート画面（SC-03）。対応パス: `GET /cart`（表示）／`POST /cart/items/{cartItemId}/quantity`（数量変更）／`POST /cart/items/{cartItemId}/delete`（削除）。テンプレート: `templates/cart/index.html`。対応コントローラ: `CartController`（`app/src/main/java/com/example/ecsite/controller/CartController.java`）。本書は `doc/詳細設計/ecsite-ER図・テーブル定義書.md` および `doc/詳細設計/ecsite-画面一覧・共通仕様書.md` を根拠に作成したカート画面単体の詳細設計書であり、実装前の新規設計である。カートへの商品追加は「ecsite-商品詳細画面設計書.md」、購入手続きは「ecsite-購入手続き画面設計書.md」を参照。

## 1. 画面項目定義

共通ヘッダー・フラッシュメッセージは「ecsite-画面一覧・共通仕様書.md」の3章・5章を参照。

### 1.1 カート明細

カートに商品が1件以上ある場合のみ表示する。明細は `cart_items.created_at` の昇順（カートに入れた順）で並べ、1行ごとに以下の項目を持つ。

| 表示名（論理名） | 種別 | 必須性 | 初期値／表示内容 | 操作可否 | 備考 |
|---|---|---|---|---|---|
| 商品画像 | 画像 | - | `products.image_url`（未設定なら代替画像） | 表示のみ | 代替テキストは商品名 |
| 商品名リンク | リンク | - | `products.name` | 遷移可 | `GET /products/{productId}` へ遷移。商品が非公開の場合はリンクにせずテキスト表示 |
| 単価表示 | テキスト表示 | - | 現在の `products.price`（例:「¥1,980」） | 表示のみ | カートには単価を保持しないため、常に最新の価格を表示する |
| 数量入力欄 | 数値入力（`type="number"`） | 必須 | `cart_items.quantity` | 入力可 | `min="1"`・`max="10"`・`required` |
| 更新ボタン | ボタン（submit） | - | 「更新」 | 押下可 | 行ごとに配置。`POST /cart/items/{cartItemId}/quantity`（`quantity`）を送信 |
| 小計表示 | テキスト表示 | - | 単価 × 数量（例:「¥3,960」） | 表示のみ | - |
| 削除ボタン | ボタン（submit） | - | 「削除」 | 押下可 | 行ごとに配置。`POST /cart/items/{cartItemId}/delete` を送信。確認ダイアログは表示しない |
| 購入不可メッセージ | テキスト（条件表示） | - | 下記のいずれか | 表示のみ | 購入できない状態の行のみ、赤字で表示 |

購入不可メッセージの表示条件:

| 条件 | 表示内容 |
|---|---|
| 商品が非公開（`is_published = false`） | 「この商品は現在購入できません。削除してください」 |
| 在庫数が0 | 「在庫切れです。削除してください」 |
| 在庫数が1以上かつ数量より少ない | 「在庫が不足しています（在庫: {在庫数}点）。数量を変更してください」 |

### 1.2 合計・操作

| 表示名（論理名） | 種別 | 必須性 | 初期値／表示内容 | 操作可否 | 備考 |
|---|---|---|---|---|---|
| 合計点数表示 | テキスト表示 | - | 「合計 {数量の合計}点」 | 表示のみ | カートに商品が1件以上ある場合のみ表示 |
| 商品合計表示 | テキスト表示 | - | 「商品合計 ¥{小計の合計}」 | 表示のみ | カートに商品が1件以上ある場合のみ表示。送料は含まない（購入手続き画面で表示） |
| 購入不可の案内 | テキスト（条件表示） | - | 「購入できない商品がカートに含まれています。数量を変更するか削除してください」 | 表示のみ | 購入不可メッセージが表示されている行が1件以上ある場合のみ表示 |
| 購入手続きへ進むボタン | ボタン（submit。`GET` フォーム） | - | 「購入手続きへ進む」 | 押下可／押下不可 | カートに商品が1件以上ある場合のみ表示。`GET /checkout` へ遷移。購入不可の行が1件以上ある場合は `disabled`（押下不可） |
| 買い物を続けるリンク | リンク | - | 「買い物を続ける」 | 遷移可 | `GET /products` へ遷移 |

### 1.3 その他

| 表示名（論理名） | 種別 | 必須性 | 初期値／表示内容 | 操作可否 | 備考 |
|---|---|---|---|---|---|
| 画面見出し | テキスト表示（`<h1>`） | - | 「カート」 | 表示のみ | - |
| 0件時メッセージ | テキスト表示（条件表示） | - | 「カートに商品が入っていません」 | 表示のみ | カートが0件の場合のみ表示 |

## 2. 入力チェック内容

### 2.1 クライアント側

- 数量入力欄に `type="number"`・`min="1"`・`max="10"`・`required` を付与する。空・1未満・11以上・小数の値ではブラウザ標準の制約検証により更新ボタンを押しても送信されない。
- JavaScriptによる入力チェックは行わない。

### 2.2 サーバー側

`POST /cart/items/{cartItemId}/quantity` 送信時に以下の順でチェックする。

| 対象項目 | チェック内容 | エラーメッセージ | 発生条件 |
|---|---|---|---|
| カート明細（`cartItemId`） | ログインユーザーの `cart_items` として存在すること | 表示なし（何もせずカート画面を再表示） | 存在しない・他ユーザーのIDを送信するリクエスト改ざん時、または別タブで削除済みの明細を更新した場合 |
| 数量 | 1〜10の整数であること | 「数量は1〜10の整数で入力してください」 | 通常の画面操作ではブラウザの制約検証により発生しない。リクエスト改ざん時のみ発生しうる |
| 数量（在庫） | 在庫数（`stock_quantity`）以下であること | 「在庫が不足しています（在庫: {在庫数}点）」 | 在庫数を超える数量に変更した場合 |

- エラーメッセージは、カート画面へリダイレクトしてフラッシュメッセージ（エラー）として表示する。
- 商品が非公開の明細に対する数量変更は、在庫チェックの前に「この商品は現在購入できません」エラーとし、数量を変更しない。

## 3. 画面処理

### 3.1 遷移元

- 商品詳細画面のカートに入れるボタン（追加後のリダイレクト）、共通ヘッダーのカートリンク、購入手続き画面のカートに戻るリンクから遷移する。
- ログインが必要。未ログインでアクセスした場合はログイン画面へリダイレクトされ、ログイン後にカート画面へ戻る（「ecsite-画面一覧・共通仕様書.md」の4章）。

### 3.2 初期表示

- `GET /cart` にアクセスすると、`CartController#show` がログインユーザーの `cart_items` と対応する `products` を取得し、カート画面を表示する。
- 非公開・在庫不足の商品も明細として表示し、1.1 の購入不可メッセージを付ける（カートから自動では削除しない）。
- 単価・小計・合計は、表示時点の `products.price` で計算する。

### 3.3 数量変更（正常時／エラー時）

- 数量入力欄を変更して更新ボタンを押下すると、`POST /cart/items/{cartItemId}/quantity`（リクエストパラメータ `quantity`）が送信される。
- **正常時**: 対象明細の `quantity` と `updated_at` を更新し、`/cart` へリダイレクトしてフラッシュメッセージ（成功）「数量を変更しました」を表示する。
- **エラー時**: 数量は変更せず、`/cart` へリダイレクトしてフラッシュメッセージ（エラー）で 2.2 のエラーメッセージを表示する。数量入力欄には変更前の数量が表示される。
- **対象明細が存在しない場合**: 何もせず `/cart` へリダイレクトする（メッセージは表示しない）。

### 3.4 削除

- 削除ボタンを押下すると、`POST /cart/items/{cartItemId}/delete` が送信される。確認ダイアログは表示せず、押下と同時に削除される。
- **正常時**: ログインユーザーの対象明細を削除し、`/cart` へリダイレクトしてフラッシュメッセージ（成功）「カートから商品を削除しました」を表示する。最後の1件を削除した場合は0件時メッセージが表示される。
- **対象明細が存在しない場合**（他ユーザーのID、削除済み等）: 何もせず `/cart` へリダイレクトする（メッセージは表示しない）。

### 3.5 購入手続き画面への遷移

- 購入手続きへ進むボタン押下により `GET /checkout` へ遷移する（画面としては「ecsite-購入手続き画面設計書.md」を参照）。購入不可の行がある場合はボタンが押下できない。

### 3.6 例外発生時の共通事項

- DBアクセス例外等が発生した場合は、「ecsite-画面一覧・共通仕様書.md」の6章のとおり500エラーページを表示する。数量変更・削除はロールバックされ、カートは変更されない。
