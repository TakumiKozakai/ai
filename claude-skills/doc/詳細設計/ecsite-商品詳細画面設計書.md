# ecsite 商品詳細画面設計書

画面名: 商品詳細画面（SC-02）。対応パス: `GET /products/{id}`（表示）／`POST /cart/items`（カートに入れる）。テンプレート: `templates/product/detail.html`。対応コントローラ: `ProductController`（表示。`app/src/main/java/com/example/ecsite/controller/ProductController.java`）、`CartController`（カートに入れる。`app/src/main/java/com/example/ecsite/controller/CartController.java`）。本書は `doc/詳細設計/ecsite-ER図・テーブル定義書.md` および `doc/詳細設計/ecsite-画面一覧・共通仕様書.md` を根拠に作成した商品詳細画面単体の詳細設計書であり、実装前の新規設計である。商品一覧画面については「ecsite-商品一覧画面設計書.md」、カート画面については「ecsite-カート画面設計書.md」を参照。

## 1. 画面項目定義

共通ヘッダー・フラッシュメッセージは「ecsite-画面一覧・共通仕様書.md」の3章・5章を参照。

### 1.1 商品情報

| 表示名（論理名） | 種別 | 必須性 | 初期値／表示内容 | 操作可否 | 備考 |
|---|---|---|---|---|---|
| 商品名（画面見出し） | テキスト表示（`<h1>`） | - | `products.name` | 表示のみ | - |
| 商品画像 | 画像 | - | `products.image_url`（未設定なら代替画像） | 表示のみ | 代替テキストは商品名 |
| カテゴリ名 | テキスト表示 | - | 対象商品の `categories.name` | 表示のみ | - |
| 価格表示 | テキスト表示 | - | `products.price`（例:「¥1,980」） | 表示のみ | - |
| 在庫状況 | テキスト表示 | - | `stock_quantity` が1以上なら「在庫あり」、0なら「在庫切れ」 | 表示のみ | 在庫数そのものは表示しない |
| 商品説明 | テキスト表示 | - | `products.description`（未設定なら空欄） | 表示のみ | 改行を保持して表示する。HTMLはエスケープする |

### 1.2 カート投入フォーム

ログイン状態と在庫により表示する項目が変わる。

| 表示名（論理名） | 種別 | 必須性 | 初期値／表示内容 | 操作可否 | 備考 |
|---|---|---|---|---|---|
| 数量セレクトボックス | セレクトボックス | 必須 | 「1」が選択済み | 選択可 | ログイン中かつ在庫ありの場合のみ表示。選択肢は1〜「在庫数と10の小さい方」 |

| 在庫切れボタン | ボタン（無効） | - | 「在庫切れ」 | 押下不可（`disabled`） | ログイン中かつ在庫切れの場合のみ、カートに入れるボタンの代わりに表示 |

## 2. 入力チェック内容

### 2.1 クライアント側

- 数量はセレクトボックスのため、選択肢（1〜在庫数と10の小さい方）以外の値は画面操作では送信できない。
- HTML5属性やJavaScriptによる入力チェックは行わない。

### 2.2 サーバー側

`POST /cart/items` 送信時に以下の順でチェックする。

| 対象項目 | チェック内容 | エラーメッセージ | 発生条件 |
|---|---|---|---|
| 商品（`productId`） | 数値であり、公開中（`is_published = true`）の商品として存在すること | 表示なし（404エラーページを表示） | 存在しない・非公開・数値でない商品IDを送信するリクエスト改ざん時、または画面表示後に商品が非公開になった場合 |
| 数量（`quantity`） | 1〜10の整数であること | 「数量は1〜10の整数で選択してください」 | 範囲外・整数でない値を送信するリクエスト改ざん時のみ発生しうる |
| 数量（カート内との合計） | カート内の同じ商品の数量と今回の数量の合計が10以下であること | 「1商品あたりの数量は10点までです（カート内: {カート内の数量}点）」 | 同じ商品を複数回カートに入れた場合 |
| 数量（在庫） | カート内の同じ商品の数量と今回の数量の合計が在庫数（`stock_quantity`）以下であること | 「在庫が不足しているためカートに追加できません（カート内: {カート内の数量}点）」 | 同じ商品を複数回カートに入れた場合、または画面表示後に在庫が減った場合 |

- 数量・在庫のエラーメッセージは、商品詳細画面へリダイレクトしてフラッシュメッセージ（エラー）として表示する。
- 「カート内の数量」は、カートに同じ商品が無い場合は 0 とする。

## 3. 画面処理

### 3.1 遷移元

- 通常は商品一覧画面の商品名リンクから遷移する。`GET /products/{id}` は独立したURLとして公開されており、未ログインでもURLを直接指定してアクセスできる。

### 3.2 初期表示

- `GET /products/{id}` にアクセスすると、`ProductController#detail` が対象商品とカテゴリを取得し、商品詳細画面を表示する。
- ログイン状態と在庫数により、1.2 のカート投入フォームの表示を切り替える。
- **対象商品が表示できない場合**: 商品が存在しない、非公開（`is_published = false`）、または `{id}` が数値でない場合は、404エラーページを表示する（「ecsite-画面一覧・共通仕様書.md」の6章）。

### 3.3 カートに入れる（正常時／エラー時）

- 数量を選択してカートに入れるボタンを押下すると、`POST /cart/items`（リクエストパラメータ `productId`・`quantity`）が送信される。
- `CartController#add` は `CartService` を呼び出し、2.2 のチェックを行う。
- **正常時**: ログインユーザーのカートに同じ商品が無い場合は `cart_items` を新規作成し（`quantity` = 送信した数量）、既にある場合は既存行の `quantity` に送信した数量を加算する。その後 `/cart` へリダイレクトし、カート画面にフラッシュメッセージ（成功）「カートに商品を追加しました」を表示する。
- **数量・在庫のエラー時**: カートは変更せず、`/products/{productId}` へリダイレクトし、商品詳細画面にフラッシュメッセージ（エラー）で 2.2 のエラーメッセージを表示する。
- **商品が存在しない・非公開の場合**: カートは変更せず、404エラーページを表示する。
- **未ログインで送信した場合（セッション切れ等）**: Spring Security により `GET /login` へリダイレクトされる。ログイン後はカートに追加されず、`/products` へ遷移する（「ecsite-画面一覧・共通仕様書.md」の4章）。

### 3.4 ログイン画面への遷移

- 未ログイン時にログイン誘導リンクを押下すると `GET /login` へ遷移する。ログイン後は `/products` へ遷移し、商品詳細画面には戻らない。

### 3.5 商品一覧画面への遷移

- 商品一覧へ戻るリンク押下により `GET /products` へ遷移する。

### 3.6 例外発生時の共通事項

- DBアクセス例外等が発生した場合は、「ecsite-画面一覧・共通仕様書.md」の6章のとおり500エラーページを表示する。カート投入処理はロールバックされ、カートは変更されない。
