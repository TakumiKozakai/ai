# ecsite 商品詳細画面設計書

画面名: 商品詳細画面（SC-02）。URL: `/products/:id`。画面コンポーネント: `app/frontend/src/pages/ProductDetailPage.tsx`。使用API: A-07 `GET /api/products/:id`（`app/backend/internal/handler/product_handler.go`）、A-09 `POST /api/cart/items`（`app/backend/internal/handler/cart_handler.go`）。本書は `doc/詳細設計/ecsite-ER図・テーブル定義書.md`、`doc/詳細設計/ecsite-画面一覧・共通仕様書.md`、`doc/詳細設計/ecsite-API設計書.md` を根拠に作成した商品詳細画面単体の詳細設計書であり、実装前の新規設計である。商品一覧画面については「ecsite-商品一覧画面設計書.md」、カート画面については「ecsite-カート画面設計書.md」を参照。

## 1. 画面項目定義

共通ヘッダー・画面メッセージは「ecsite-画面一覧・共通仕様書.md」の3章・5章を参照。

### 1.1 商品情報

| 表示名（論理名） | 種別 | 必須性 | 初期値／表示内容 | 操作可否 | 備考 |
|---|---|---|---|---|---|
| 商品名（画面見出し） | テキスト表示（`<h1>`） | - | `products.name` | 表示のみ | - |
| 商品画像 | 画像 | - | `products.image_url`（未設定なら代替画像） | 表示のみ | 代替テキストは商品名 |

## 2. 入力チェック内容

### 2.1 クライアント側

- 数量はセレクトボックスのため、選択肢（1〜`maxQuantity`）以外の値は画面操作では送信できない。
- それ以外の入力チェックは行わない。

### 2.2 サーバー側

A-09 `POST /api/cart/items` 呼び出し時に以下の順でチェックする。

| 対象項目 | チェック内容 | エラーメッセージ | 発生条件 |
|---|---|---|---|
| 商品（`productId`） | 数値であり、公開中（`is_published = true`）の商品として存在すること | 表示なし（`404 NOT_FOUND`。画面は「ページが見つかりません」を表示） | 存在しない・非公開・数値でない商品IDを送信するリクエスト改ざん時、または画面表示後に商品が非公開になった場合 |
| 数量（`quantity`） | 1〜10の整数であること | 「数量は1〜10の整数で選択してください」（`400 VALIDATION_ERROR`、`fieldErrors.quantity`） | 範囲外・整数でない値を送信するリクエスト改ざん時のみ発生しうる |
| 数量（カート内との合計） | カート内の同じ商品の数量と今回の数量の合計が10以下であること | 「1商品あたりの数量は10点までです（カート内: {カート内の数量}点）」（`400 CART_QUANTITY_LIMIT`） | 同じ商品を複数回カートに入れた場合 |
| 数量（在庫） | カート内の同じ商品の数量と今回の数量の合計が在庫数（`stock_quantity`）以下であること | 「在庫が不足しているためカートに追加できません（カート内: {カート内の数量}点）」（`400 INSUFFICIENT_STOCK`） | 同じ商品を複数回カートに入れた場合、または画面表示後に在庫が減った場合 |

- 「カート内の数量」は、カートに同じ商品が無い場合は 0 とする。
- 数量・在庫のエラーメッセージは、商品詳細画面にとどまったまま画面メッセージ（エラー）として表示する。

## 3. 画面処理

### 3.1 遷移元

- 通常は商品一覧画面の商品名リンクから遷移する。`/products/:id` は未ログインでもURLを直接指定して表示できる。
- ログイン画面からの戻り先としても遷移する（1.2 のログイン誘導リンク経由でログインした場合）。

### 3.2 初期表示

- `/products/:id` を表示すると、A-07 `GET /api/products/:id` で商品を取得し、商品詳細画面を表示する。
- ログイン状態（共通ヘッダーで取得した `GET /api/me` の結果）と `inStock` により、1.2 のカート投入フォームの表示を切り替える。
- **対象商品が表示できない場合**: `:id` が数値でない場合はAPIを呼び出さず、A-07 が `404` を返した場合（存在しない・非公開）はそのまま、「ページが見つかりません」画面を表示する（「ecsite-画面一覧・共通仕様書.md」の6章）。

### 3.3 カートに入れる（正常時／エラー時）

- 数量を選択してカートに入れるボタンを押下すると、A-09 `POST /api/cart/items`（`{ "productId": {id}, "quantity": {数量} }`）を呼び出す。
- バックエンドは 2.2 のチェックを行い、ログインユーザーのカートに同じ商品が無い場合は `cart_items` を新規作成し（`quantity` = 送信した数量）、既にある場合は既存行の `quantity` に送信した数量を加算する。
- **正常時**（`201`）: 共通ヘッダーのカート数量を更新し、`/cart` へ遷移して、カート画面に画面メッセージ（成功）「カートに商品を追加しました」を表示する。
- **数量・在庫のエラー時**（`400`）: カートは変更されない。商品詳細画面にとどまり、画面メッセージ（エラー）でAPIの `message`（`VALIDATION_ERROR` の場合は `fieldErrors.quantity`）を表示する。数量セレクトボックスの選択は変えない。
- **商品が存在しない・非公開の場合**（`404`）: カートは変更されず、「ページが見つかりません」画面を表示する。
- **未ログインの場合**（`401`。有効期限切れ等）: `/login` へ遷移し、遷移元としてこの画面のURLを渡す。ログイン後は商品詳細画面に戻る（カートには追加されていないため、再度カートに入れるボタンを押す）。

### 3.4 ログイン画面への遷移

- 未ログイン時にログイン誘導リンクを押下すると `/login` へ遷移する。ログインに成功すると、この商品詳細画面に戻る（「ecsite-画面一覧・共通仕様書.md」の4.4）。

### 3.5 商品一覧画面への遷移

- 商品一覧へ戻るリンク押下により `/products` へ遷移する。

### 3.6 例外発生時の共通事項

- A-07・A-09 が `500` を返した場合、またはバックエンドに接続できない場合は、「ecsite-画面一覧・共通仕様書.md」の6章のとおりシステムエラー画面を表示する。カート投入処理はロールバックされ、カートは変更されない。
